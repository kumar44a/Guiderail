## What each step was and what was decided

- **Baseline**: Starting point: sentence scoring in isolation, validator v1. start
- **+ context-aware sentence scoring**: Score a sentence together with its document title and section. ACCEPTED: answer correctness up on synthetic, unchanged on real.
- **+ validator v2**: Question support measured against the answer, idf-weighted coverage, number-and-unit check, metadata as evidence. ACCEPTED: out-of-corpus false accepts halved on synthetic; stress set catches far more bad answers.
- **+ list/continuation rules**: A lead-in ending in ':' brings its list; 'This/It/They...' sentences continue the previous one. ACCEPTED: real-corpus correctness and validated precision rose.
- **+ lexical re-ranker (weight 0.5)**: Re-order the top 30 candidates by best-sentence coverage of the question. ACCEPTED (weights 0.5 and 1.0 performed alike; the smaller was chosen): large retrieval gains on both corpora.
- **tried: scale relevance by unknown question words**: Penalise questions containing words that appear nowhere in the corpus. REJECTED: fixed one out-of-corpus case but collapsed decision accuracy and flagged many good answers.
- **LLM generator, first prompt**: Claude, evidence-only prompt, same retriever and validator. baseline for the LLM mode
- **LLM generator, tightened prompt**: Plain text, no commentary or markdown, reuse the guideline's wording. ACCEPTED: fewer correct answers withheld, validated precision held.
- **Frozen configuration, extractive (real corpus = 5 documents)**: No change in configuration; real corpus now 5 documents and 17 more queries. Reported as is.
- **Frozen configuration, LLM (real corpus = 5 documents)**: Same, live LLM. Reported as is.
- **Shipped configuration (extractive): hybrid retrieval, validator rounds 2 and 3**: Fresh runs of the final settings; real dev now includes all later dev queries. Reported as is; see sections 10 to 12 of the report for how each part was judged.
- **Shipped configuration (LLM)**: Same, live Claude runs. Reported as is.

## Experiments not reproducible from the repository

- **IDF-weighted embeddings** (two variants) were tried on retrieval only and **rejected**: they raised Hit@5 on some corpora but lowered MRR on both, failing the rule. The code was reverted. Console figures at the time: synthetic dev MRR 0.690 → 0.647 and 0.655, real dev MRR 0.483 → 0.471 for both variants.

## Label edits made after seeing dev outputs

- **S09**: added the alternative "should not be worn between patients" to the expected fact, after an LLM answer used that correct paraphrase and was scored wrong. Answer matching was also made stem-aware ("acts" matches "act"), which applies to every system equally.
- **Stress set**: cases touching a test-split topic were re-worded so no test-split question text is used in development.
